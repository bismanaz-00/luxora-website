# 🛋️ Luxora Furniture Website

A modern and responsive furniture website designed to provide a clean, elegant, and user-friendly browsing experience.

This project focuses on creating a visually appealing frontend using **HTML5 and CSS3**, with responsive layouts and a modern furniture-inspired design.

## 🌐 Live Demo

🔗 **[View Live Website] https://luxora-furniture-website.vercel.app/**

## ✨ Features

- Modern and elegant furniture website design
- Clean and organized user interface
- Responsive layout for different screen sizes
- Attractive product and content sections
- Easy-to-use navigation
- Carefully designed typography and spacing
- User-friendly browsing experience

## 🛠️ Technologies Used

- **HTML5** — Website structure and content
- **CSS3** — Styling, layout and responsive design
